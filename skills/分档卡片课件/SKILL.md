# 分档卡片课件

## 先问清楚再动手

这个用户给的指令通常很短（中位 30 字），审美类需求不问清楚必返工。**动手前先要到这三样**：

1. **参照物**：是照着 985 那版做，还是有别的样子要参考？（有截图最好）
2. **数据源在哪**：Word / Excel / 已有 HTML / 直接口述？表格是嵌进 Word 的 Excel 对象时，
   要从 `word/embeddings/*.xlsx` 解，别从正文抓
3. **每条卡片放哪几栏**：默认「优势/地域/特殊项」三栏，换题材要重新定（见 `references/数据结构.md`）

已经明确的不用再问。问完直接做，不要边做边问。

## 五步

### 第 1 步　把内容整理成 DATA

读 `references/数据结构.md`，把源内容整理成那个 JSON。重点：

- 每条的 `fields` **只放名词，不放整段话**。原稿里的整段描述是给主播口播的，不上卡片
- 原稿里"全国第一""王牌""尤其是"这种单独点名的，在 `v` 里用 `<b>` 套住，卡片上会加重显示
- 数字指标（保研率/升学率/占比…）放 `metrics`，**不要再在 fields 里重复一遍**
- 原稿没写的留空字符串，不要编，也不要写"暂无"

整理时把**数据存疑的地方单独记下来**（前后矛盾、明显异常值、空括号），最后一并交给用户核对——
不要自己猜着填。

### 第 2 步　套骨架

复制 `assets/deck-template.html`，把 `/*DATA_START*/…/*DATA_END*/` 之间换成第 1 步的 DATA。
**除此之外不要改 JS 和 CSS**——那些数值是返工十几轮定下来的，见 `references/规格清单.md`。

文件名 = `cover.title`，同时也是导出文件名和缓存键。

### 第 3 步　配图标（可选）

条目是院校/机构/品牌这类有标识的，加图标水印会好看很多：

```bash
python3 <skill>/scripts/fetch_logos.py 你的deck.html --size 220
```

脚本会走维基 API 批量抓、串行下载、校验、内嵌。跑完看它打印的三类问题：
没主图的、文件名不像图标的、下载失败的——**都要人工过一遍**，抓到校门照片当校徽很难看。

图标是各机构的注册标识，内部课件水印属常见用法；**对外发布或商用前提醒用户自行确认授权**。

### 第 4 步　自己验，别让用户当测试员

文件超过约 512KB 时预览面板打不开（内嵌图标后必然超）。做法：
生成一份只留 3~4 个图标 base64 的精简副本放**项目目录里**（桌面等项目外路径预览面板也打不开），
用它验渲染；完整文件用脚本静态校验。

必验清单：

- [ ] 控制台无报错（改过 JS 就一定要看，TDZ 报错会直接白屏）
- [ ] 所有条目卡尺寸都是 880×660，没有被内容撑破
- [ ] 折叠态标题排不换行（拿最长的名字 + 最长的指标试）
- [ ] `↓` 从头连按到底不报错，跨档能自动展开下一档
- [ ] `1`~`6` 跳档后按 `↓` 从该档第一条开始
- [ ] 「回到总览」不会把讲过的卡片收起来
- [ ] 编辑模式下的排版和非编辑模式一致（标签照样是标签）
- [ ] 深色/浅色两套主题都看一眼
- [ ] 图标水印浓淡一致（深底浅底的都要抽查）

### 第 5 步　交付

- 放到用户存这类物料的文件夹（问一下，别默认放工作目录）
- **改前先备份**（`xx.vN备份.html`），这个用户会自己在页面上改文字，绝不能整份覆盖他改过的东西
- 同目录如果有导航页 / 使用说明，一并更新——工具改了说明没改，是最容易掉链子的地方
- 把"数据存疑清单"和"我改了什么"一起说清楚

## 这套课件的取舍（别推翻）

| 决定 | 为什么 |
|---|---|
| 三种卡同尺寸 4:3 | 每张都要能单独占一屏讲，切换时画面不跳 |
| 讲解定位固定在画面左中 | 主播站右侧，位置固定摄像机构图才稳 |
| 只放名词、做成标签 | 电视上没人读整段话；标签是给主播提词的 |
| 讲过的卡片不自动收起 | 主播随时要回头指前面讲过的 |
| 单文件 HTML，图标内嵌 | 拷到哪都能用，不依赖服务器和素材文件夹 |
| 页面内改文字 + 导出覆盖 | 用户自己改文案，不用回来找我 |

## 复盘补充（2026-10-13）

这套是 985／211 那 10 天里长出来的，当时返工最多的几条，开工前先看：
- **字号按成片在手机上看得清来定**，换算见 editable-video-deck 的 `references/phone-legibility.md`；“突出”＝字号＋字重＋颜色一起动。
- **首版附源稿对账**：每档几所、每个字段空几所、顺序和文案是否一致（211 首版缺北交北外、表格里的数没贴）。
- **讲解定位、展示墙这类动线，先出三帧分镜**再写代码（“4:3 板块”曾被理解成切换视图）。
- **批量处理校徽先出全部结果的总览图**，确认后再嵌（985 校徽两轮越改越坏）。
- 院校盘点、排行类新课件，现在默认走 editable-video-deck 的分档画布（国家电网那套）；这套留作 985／211 现有课件的维护参考。
