# 踩过的坑

985 六大梯队那版返工了十几轮，下面每一条都是返过工的。照着躲。

## 1. em 的基准是父元素，不是卡片

标签 `.tag` 嵌在字段值 `.v`（`2em` = 32px）里面。
写 `.tag{font-size:1.875em}` 想要 30px，实际得到 **60px**（1.875 × 32），
13 张卡当场撑破 4:3。

**规矩**：标签写 `.95em`（相对字段值），占位符、`.none` 同理。
只有直接挂在 `.node` 下的元素（条目名、指标、字段名）才用相对 16px 的 em。

## 2. 图标水印：不能拿 alpha 当蒙版

第一版用校徽 PNG 的透明通道当 `mask-image`，填主题色。
结果：**只有线条镂空型的校徽有效**（华南理工、东北大学）。
实心圆校徽（北理工、武大、东南、西北农林）整个圆都不透明，抠出来是一块纯色圆饼，
图案细节全丢。

## 3. 图标水印：也不能拿原图去色染色

第二版改成 `background-image` + `grayscale(1) sepia(1) saturate(3.2) hue-rotate(...)`。
细节是回来了，但 **38 个校徽的底色明暗天差地别**：
白底的（浙大、复旦、南大）淡到看不见，深底的（北理工、武大）连圆底一起被染成实色，
变成一块块扎眼的彩色印章压在文字上。比第一版还糟。

## 4. 正解：canvas 墨稿归一化

页面加载时用 canvas 逐个处理（`inkify()`）：

1. 算非透明像素的平均亮度，判断这枚图标是浅底还是深底
2. 浅底取深色笔画（`1 - lum`），深底**自动反相**取亮色笔画（`lum`）
3. 圆底本身丢掉，只留笔画形状，输出成白色 + alpha 的 PNG 当蒙版
4. 再填该档主题色

这样不管原图什么底色，38 个出来浓淡一致，且都是纯单色线稿。

配套细节：
- `visibility:hidden` → 全部算完加 `body.inkready` 才显示，避免闪一下原图
- `rebuild()` 后要重新 `paintLogos()`，否则改文字一次水印就没了
- 结果缓存在 `INK{}` 里，同一图标只算一次

## 4b. 判「深底」不能只看亮度

墨稿归一化里判断图标是浅底还是深底，一开始只算了非透明像素的平均亮度。
但多数图标是**透明底 + 深色线条**，非透明像素本来就全是深色线条 → 平均亮度低 → 全被判成"深底"
→ 走反相分支 → 笔画浓度只剩应有的四成，水印淡到看不见（37 个校徽一个不落全中招）。

**正解**：深底 = 大面积不透明 **且** 整体偏暗：

```js
const deep = n / (w * h) > .5 && sum / n < .5;   // n = 非透明像素数
```

判对之后，实心圆底的（地大、武理、哈工程那类，实心度 53%~79%）才走反相，
其余走正常分支，墨量翻倍。**改完一定要抽查浅底和深底各几个**，别只看一个。

## 5. localStorage 会把新版盖掉

页面把用户改过的内容存在 localStorage，下次打开优先用缓存。
卡片结构一改版，**旧缓存里的旧字段会把新数据结构盖掉**，看起来像"改了没生效"。

**规矩**：`DATA.ver` 版本号，对不上就丢弃缓存并 `removeItem`。改数据结构就升版本号。

## 6. 常量定义顺序（TDZ）

`applyFS()` 的调用一度被插到 `const applyFS = ...` 前面，
`const` 在 TDZ 里 → `ReferenceError` → **整页白屏**。
所有初始化调用必须在定义之后。改完先看控制台有没有报错再交付。

## 7. 延迟的自动缩放会冲掉讲解定位

「展开全部」「全部收起」里有 `setTimeout(fit, 470)`。
点完这两个按钮后半秒内按 ↓，讲解定位刚摆好就被 `fit()` 冲掉。

**规矩**：`NAV` 序号，每次讲解定位自增；延迟回调里核对序号，对不上就不执行。

## 8. 编辑模式必须所见即所得

标签类字段一度在编辑模式显示原始整段文字（为了能编辑），
结果**在编辑模式调字号看到的不是讲课时的排版**，等于白调。

**正解**：编辑模式照样渲染标签，源文本另起一行小灰字（`.src`，`.62em`）挂 `data-e`，
只有那行可编辑。`body.editing .v:has(.src){outline:none}` 去掉标签容器的虚线框。

## 9. 折叠卡一行装不下就会换行

条目名 8 字 + 地域 + 「40~50%」这种长指标，宽度不够会 wrap，卡片高度参差不齐。
折叠态宽度定 680，`.nums div{white-space:nowrap}`。
改字号或加字段后**要实测最长的那条**（中国科学技术大学 + 40~50%）。

## 10. 总览页会被大卡撑爆

三种卡统一 880 宽之后，六列横排 = 5616px，`fit()` 缩到 32%，总览页字很小。
`layoutV` 里列宽取 `max(COL_W, tn.w)`——**收起的档只按分档卡占宽**，
展开哪一档哪一列才变宽。

## 11. 验证时预览面板打不开大文件

内嵌图标后文件 1.9MB，预览面板加载不了（约 512KB 上限）。
**做法**：生成一份只留 3~4 个图标 base64 的精简副本（其余 `.lg-N` 规则删掉）放项目目录里验证，
完整文件用脚本逐项静态校验。桌面等项目外路径预览面板也打不开，验证副本要放在项目目录。

## 12. 维基批量下图会被限流

并发 8 个 curl 有一半返回 HTML 错误页（文件大小都是 2175 字节，`file` 显示 HTML）。
**做法**：串行 + `sleep 0.6` + 带 `User-Agent`。下完必须用 `file -b` 逐个验一遍是不是真 PNG。

## 13. 图标可能抓到的不是图标

维基条目主图有时是校门照片而不是校徽。
**做法**：看缩略图 URL 里的原始文件名，含 `logo/seal/emblem/badge/徽/crest` 的基本没问题；
不含关键词的单独开图确认。别跳过这步。
