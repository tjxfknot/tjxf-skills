# 数据结构

模板里 `/*DATA_START*/ … /*DATA_END*/` 之间那段就是全部内容。
**换题材只改这段，不动下面的 JS。**

```jsonc
{
  "ver": 1,          // 数据结构版本号。改了字段就 +1，否则浏览器旧缓存会盖掉新版
  "fs": 1,           // 字号总系数，编辑模式滑块存这里
  "logo": 0.3,       // 图标水印透明度，0 = 不显示

  "cover": {
    "title": "985院校 六大梯队",   // 标题卡正文 + 左上角标题 + 导出文件名，都取这个
    "sub":   "张凡老师短视频文稿",  // 左上角小字
    "unit":  "所",                 // 计数单位：「11 所」「7 条」「5 个」
    "lead":  "开场口播词",          // 只存不显示，卡片上不放
    "wall":  ["985院校的", "六大梯队"]  // 展示墙的两行大标题；不写就把 title 按空格劈两半
  },

  "tiers": [
    {
      "n": 1,                       // 档位序号，对应键盘 1~6 和配色 --t1~--t6（最多 6 档）
      "title": "第一梯队",           // 分档卡大标题
      "short": "断崖领先",           // 标题后半截 + 底部图例
      "punch": "断崖式领先，不用比",   // 口播金句（彩色那行）
      "ruler": "凭什么这么分：…",      // 判断标准（虚线下面那段）
      "items": [
        {
          "name": "清华大学",
          "note": "北京",            // 折叠态标题排上的小 pill；展开态自动隐藏
          "metrics": [               // 与条目名同排的数字，建议 2 个，最多 3 个
            { "v": "70%",    "k": "保研" },
            { "v": "79.64%", "k": "升学" }
          ],
          "fields": [                // 展开态的栏目：几栏、叫什么，全由这里决定
            { "k": "优势专业", "v": "电气、计算机、机械", "tag": true },
            { "k": "地域",     "v": "北京" },
            { "k": "特殊班",   "v": "已实行书院制改革…<b>新雅书院</b>…", "tag": true, "boldOnly": true }
          ]
        }
      ]
    }
  ]
}
```

## 字段怎么选

| 想要的效果 | 怎么写 |
|---|---|
| 一栏纯文本 | `{"k":"地域","v":"北京"}` |
| 一栏标签（若干名词） | 加 `"tag": true`，`v` 用顿号分隔：`"计算机、软件、机械"` |
| 标签里某几个要加重 | 在 `v` 里给那几个套 `<b>`：`"数学、<b>口腔医学</b>"` |
| 原文是整段话，只想上卡片里那几个名词 | `"tag": true, "boldOnly": true`，把要上卡的名词在 `v` 里套 `<b>`，其余原样留着（讲课时能看到全文，卡片上只出名词） |
| 这栏还没有内容但要留位 | `"v": ""` —— 非编辑态显示「待补」，编辑态可直接补 |
| 这栏根本不要 | 从 `fields` 数组里删掉，整栏不显示 |

## 几条硬规矩

- **`metrics` 里的东西不要再在 `fields` 里重复一遍**（985 那版一开始「升学质量」栏和上面两个数字重复，被要求删掉）
- **`fields` 建议 2~4 栏**。4:3 的板子里栏目太多会挤，太少会空（内容块是竖向均分的）
- **`v` 里不要放整段描述**，长句子在电视上讲课时没人看，讲的人自己会说
- **「无推荐 XX」「暂无」这类空话直接留空**，别写进去
- `tiers` 最多 6 档（配色和数字键 1~6 就这么多）；条目数不限，但一档超过 12 条时总览页会很长
- 改了 `fields` 的栏目结构，记得把 `ver` +1

## 图标水印

`LOGO` 映射（条目名 → 序号）和 `.lg-N` 的 base64 由 `scripts/fetch_logos.py` 自动写入，
手动不用碰。没有图标时留空 `const LOGO = {}` 即可，卡片照常工作。
