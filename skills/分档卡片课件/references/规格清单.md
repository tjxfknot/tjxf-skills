## 字号档位

卡片内所有字号用 **em**，基准是 `.node{font-size:calc(16px * var(--fs,1))}`，
`--fs` 由编辑模式里的滑块控制（0.7~1.6），存进 `DATA.fs` 随导出带走。

**展开态条目卡**
- 条目名 `2.875em`（46px）
- 指标数字 `2.625em`（42px）／指标标签 `1.25em`（20px）
- 字段名 `1.25em`（20px），字距 `.16em`
- 字段值 `2em`（32px），行高 1.5
- 标签 `.95em` —— **相对字段值算**，不是相对卡片

**折叠态条目卡**（宽 680，一行装下"名字 + 地域 + 两个指标"）
- 条目名 `1.875em`（30px）／指标 `1.75em`（28px）／指标标签 `1em`

**分档卡**
- 标题 `3.5em`（56px）／口播句 `2.125em`（34px）／判断标准 `1.625em`（26px）／档位角标 `1.25em`

**标题卡**
- 一行横排居中 `4.75em`（76px），不放介绍小字（介绍靠口播）

## 卡片内容规则

- 指标（保研率/升学率这类）**与条目名同排**，靠右对齐，不要叠在下面
- 字段值凡是"若干个名词"的（专业名、班型名）一律**做成标签**，只放名字，不放整段描述
- 原稿里用 `<b>` 标出来的（"全国第一""王牌"）渲染成加重标签
- 已经在标题排出现过的信息（如升学质量＝那两个数字）**不再单列一栏**
- 「无推荐 XX」这类空话不显示，整栏隐藏
- 原稿没写的字段留「待补」占位，用改文字补
- 展开态隐藏标题排的地域 pill（下面字段里已经有）

## 键盘（讲课主用法）

| 键 | 作用 |
|---|---|
| `↓ / → / 空格` | 讲下一张。顺序＝标题卡 → 第一档总览 → 该档条目 → 第二档总览 → … 自动展开并归位 |
| `↑ / ←` | 上一张 |
| `1`~`6` | 跳到第 N 档总览卡 |
| `0` | 回总览（**讲过的卡片不收起**） |
| `W` | 展示墙 |
| `H` | 藏起所有界面（拍摄用） |
| `L` | 校徽水印开关 |
| `F` | 全屏 |
| `E` | 改文字 |

翻页笔发的就是 →/←/PageDown/PageUp，都要接住。

## 展示墙（开头结尾的背景画面）

- 卡片数刚好铺满：45 张 = 9 列 × 5 行。**列数按总卡片数算，让最后一行不留空**
- 间隙 60px（屏上约 19px）
- 按 cover 缩放 ×1.02，宁可两侧出血也不留边
- 顺序打散：`(i * 17) % n`（17 与 45 互质），同色卡片不会挤成一块
- 中间压标题：白色第一行 + 纯色黄第二行（`#f0c24e`），不要渐变、不要装饰线
- 暗罩：径向渐变（中心 92% → 边缘 20%）+ 整体压暗 32%

## 校徽 / 图标水印

- 位置：卡片 47.8% / 57.7% 处居中，直径占卡宽 50%（440px）
- 默认透明度 30%，可在编辑模式滑块调 0~60%
- **必须做墨稿归一化**（见 踩坑记录.md），否则深底浅底的图标浓淡差一倍
- 填色用该档主题色，跟着配色走
