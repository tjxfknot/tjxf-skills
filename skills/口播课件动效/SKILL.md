# 口播课件动效

翻页课件的动效只有三件事：**逐层浮现**、**数字滚上来**、**转场**。
难的不是做出来，是四个不做就会翻车的兜底。

**动线和形态先确认**：要是需求是“转到这里放大、转走缩小”“卡片从墙里飞到讲解位”这类动线或形态，先出三帧分镜（静止、转到一半、到位：谁不动、谁移动、谁变大）给用户选，再写代码。先确认静止、途中和到位三个状态，可以减少对移动关系的误判。

运行时 `assets/deckmotion.js`，无依赖，直接内联。CSS 按配置自动生成，不用手写 delay。

## 装

```html
<script>/* deckmotion.js 全文 */</script>
<script>
  DeckMotion.init({
    slide: '.slide',                     // 页容器
    active: 'active',                    // 当前页的类名
    rise: [                              // 数组顺序 = 浮现顺序
      '.rank-title',
      '.rank-desc',
      { sel: '.card', stagger: .11 }     // 同级多个，彼此再错开 .11s
    ],
    roll: '.rank-title',                 // 这个元素里的数字会滚上来
    editingClass: 'editing'              // 编辑模式的 body 类名
  });

  // 宿主每次翻页后调一次
  function showSlide(i){ …原有逻辑…; DeckMotion.enter(slides[i]); }
</script>
```

| 选项 | 默认 | 说明 |
|---|---|---|
| `rise` | `[]` | 浮现顺序。字符串或 `{sel, stagger}` |
| `dur` | `.72` | 单个元素的浮现时长（秒） |
| `gap` | `.14` | 相邻层的间隔 |
| `lead` | `.06` | 第一层的起始延迟 |
| `shift` / `blur` | `26` / `5` | 从下方多少 px 浮上来、起始模糊 |
| `roll` | — | 要滚数字的选择器 |
| `rollDur` | `820` | 滚动时长（毫秒） |
| `maxStagger` | `8` | 同级元素最多错开几个 |

## 节奏怎么定

口播的节奏比好看重要。**主播讲到哪，内容出到哪**。

- 单层 `.72s`，层间 `.14s` —— 一页三四层，总共 1 秒出完，跟得上正常语速
- 层数别超过 5。卡片内部的小标签**不要**再逐个飞，54 个标签逐个出要等十几秒
- 卡片这类同级元素用 `stagger`，`.11s` 左右，比层间隔小一点
- 页眉、页码、进度条**不参与动画**。它们是框架不是内容，跟着飞会显得廉价

## 四个坑，都踩过

### 1. 页面不在前台，`fill-mode:both` 会把整页摁成看不见 ⚠️

最狠的一个。CSS 动画在后台标签**根本不播**，而 `animation-fill-mode: both` 会让元素
停在 `from` 态——也就是 `opacity: 0`。**整页白屏**。
直播软件采集隐藏窗口、用户切走过再切回来、投屏方案，都会中招。

`DeckMotion.enter()` 里那个超时就是干这个的：到点给页容器打上 `dm-done`，
动画整个卸掉，元素回到自然可见状态。**别删那个 setTimeout。**

CSS 写法上也要配合——动画只挂在 `:not(.dm-done)` 上：

```css
.slide.active:not(.dm-done) .card { animation: dmRise .72s … both }
```

### 2. 数字滚动别用 rAF

标签页不在前台时 `requestAnimationFrame` 一帧都不跑（实测 500ms 内 0 帧），
数字会僵在起点，直到兜底超时才跳到终值。
用 `setInterval(…, 40)`：顶多被限流到 1s 一次，但最后总能走完。25fps 对数字足够。

### 3. 滚动的目标值要从当前文字现读，不能写死

页面装了编辑台的话，用户会把「670分」改成「675分」。
如果滚动用的是写死的 `data-n=670`，**滚完就把人家的修改覆盖了**。

正确做法：每次滚之前从 `el.textContent` 里现读数字；
结束时把**原样的 innerHTML 整个贴回去**（连 `<span class="unit">分</span>` 一起），
保证动画不在内容里留下任何痕迹。

### 4. 编辑模式必须关掉动效

不关的话，用户每改一个字触发重绘，元素就重新飞一次，根本没法编辑。

```css
body.editing .slide *{animation:none!important;opacity:1!important;transform:none!important}
```

顺带把 `prefers-reduced-motion` 也接上，这是无障碍的基本盘。

## 怎么验

**在面板浏览器里基本拍不到动画中间帧**，因为页面被判为后台（`visibilityState: hidden`），
CSS 动画不播、rAF 不跑。连拍三张截图会得到三张一模一样的完成态。

所以：

1. **用计算样式验配置**，别靠截图：
   `getComputedStyle(el).animationDelay` 逐层读出来，确认阶梯是 `.06 / .20 / .34 / .45`
2. **验兜底**：进场后等 1.7 秒，读 `opacity` 必须是 `1`（不是 0）
3. **验滚动**：把 `dur` 临时调到 5000ms 再采样，才抓得到中间值
   （820ms 的时长会被后台的 1s 限流整个跨过去）
4. **验编辑模式**：切进编辑模式后读 `animationName`，必须是 `none`

真实效果让用户自己打开看——这是少数几个"必须人眼确认"的地方。

## 用在哪几份上了

- 浙大 2026 选专业（28 页）：`.anim` + `--i` 手写 delay 的早期版本
- 哈工大专业选择指南（12 页）：nth-child 自动分配 + 分数滚动 + `anim-done` 兜底
