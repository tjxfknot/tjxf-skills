# 决策规则

## 1. 定骨架

- 原稿分页标记（【第N页】等）是硬分页，不自行合并或拆开；确实放不下时拆成“N-1／N-2”并告诉用户。
- 未标号段落归当前页；第一页之前的开场白是备注，不另开页（除非用户要）。
- 层级（梯队、分档、章节）做章节导航，不另占画面。
- 删除线文字剔除；口播里的评价、推测、统计口径张力写进页 note（给主播看，不上屏）。
- 每个原稿段落有去向：上屏／只口播／备注／删除（写理由）。遗漏≠删除。

## 2. 内容关系 → 版式

| 内容关系（先问“这几条之间是什么关系”） | 首选 | 备选／注意 |
|---|---|---|
| 一个上级包含几个并列项；章节／梯队总览 | `tree`（上级有独立说明时 `root` 母卡） | 并列项≥5 → `rows` 或拆页 |
| 有先后的路径、培养流程，条目说明长 | `steps` | 恰好 3 步且标题短 → `flow` |
| 恰好 3 步，每步标题 ≤7 字 | `flow` | 标题长 → `steps` |
| 一分为二（两条路、两类入口）的引入页 | `fork` | 两边都要展开细节 → 各自成页 |
| 3–4 个平行条目，名字较长 | `rows` | 条目短且要对比 → `grid2` |
| 项目—所属单位—范围 三元关系 | `proj` | — |
| 大类→学院→专业，重点是学院 | `college`（学院大字，专业作说明） | 重点是专业 → `rows`，学院作标签 |
| 4 个短条目并列对比 | `grid2` | 长名字不塞 2 列 |
| 计数汇总、结尾回顾（有明确数字） | `sum` | 只有数字页用强调色放大 |
| 多个对象，各有同样几维详情（合作／培养／专业／条件） | `master`（左列对象，右侧只显示正在讲的） | 维度≥5 或每维很长 → 每对象一页 |
| 7 张左右的密集清单，位置可能要调 | `bh` 两列（`cells` 定位置，`maxWidth:1072`，`compact`） | ≥9 张 → 拆页 |
| 一个上级包含 2–5 个下级，要“画出关系”（结构图方向） | `htree`（根＋分支连线；下级是名单时 `opts.chips`） | 分支进人物框区会自动收窄，长标题先减字号 |
| 名单、班型清单，重在“有哪些、有多少” | `chips` 标签块 | 多列时底部别进人物框区（maxWidth 1072 或短卡放最右列）；长名一项一行写 |
| 三档／三个梯队总览、开场 | `podium` 领奖台（第一张居中最高） | 台宽×3＋间距 ≤1076；补充信息放第四张 |

外部灵感（未直接采用，需要新版式时参考）：html-ppt 的 comparison／flow-diagram／mindmap，歸藏瑞士风的“重点大字页”（章节页、结论页）、比较表（统一维度逐行出现）。新增版式走 editable-video-deck 的维护流程，先查骨架重名。

## 3. 容量与字号（1600×1200 画布）

- 层级：页标题 72、重点 60、说明 44、类别标签≈32。超密页说明可降 40／36，**重点保持 60**。
- 字号来历：参考 PPT 28pt/540pt≈5.2% 画高；手机截图每字 33.8px/919px≈3.7% 屏宽≈15dp → 画布重点 60px；手机 dp≈画布px×0.26。前提是画布铺满视频宽度（电视拍摄未实测）。
- 手机可读性须在目标设备与成片画幅中验证；系统字体下估算存在误差，以浏览器和实际回放为准。
- 卡片区：单行页标题时卡片从 y≈276 开始，安全底线 y=1120；可用高度≈844px。
- 单张一行式卡（标题 1 行＋说明 1 行）≈170px，每多一行说明 +62（44px×1.4），卡间距 20。→ 单列一页 4 张一行卡最舒服，最多约 4 张＋4 行额外说明。
- 一行字数上限（60px 重点）：全宽约 22 字；三栏约 7 字；两列约 11 字；1/3 列约 7 字。
- 右下人物框（x1140–1484、y780–1120）：进入 y780 以下的单列卡自动收窄到 1072（tree 1012、steps 996），说明会多折行——规划时就按窄宽估。多列版式底部进入该区时，把 width 设 1072。
- 类别标签栏宽 labelw：最长标签字数×32＋余量（2 字≈80、3 字≈110、4 字≈150）。

## 3.5 节奏（2026-10-06，capacity_check.py 会提示）

- 同一版式连用不超过 3 页；超过就中间换一种，或把其中一页做成总览／汇总。**rows／proj／college 视觉上算同一种**（都是整行卡片往下叠），合计别超过全套三分之一。
- 8 页以上至少用 4 种版式（按内容关系换，不为花样硬换；可读性优先）。
- 7 张卡以上的密集页不连着放两页以上：拆页，或中间插一页汇总（sum）或树形总览。
- 下半部空（估计卡底高于 y600）：放大重点／说明字号或间距，重点最大 72；全宽卡底仍在 y780 以上。
- 参考歸藏“每 3–4 页一个大字页、明暗交替”，口播课件按上面四条落地；明暗交替不照搬（整套一个主题包，避免拍摄时画面忽明忽暗）。

## 4. 文字规则

- 屏幕写原稿原话的短句；不留“原稿称／推测／待核实／关注…”这类草稿痕迹。
- 原稿找不到出处 → `【待核】…`（屏幕黄底虚线框），列入待核清单给用户补或删。
- 不自动加粗、不高亮（剪辑做）；行首“键：值”（键≤7字）会自动加粗键，这是唯一例外，只在 master／详情类用。
- 与标签重复的备注不写；同列重复标签只显示一次（bh 自动处理）。
- 断句点：只在 、／，；：＋。）｜空格 之后断行。一行一个完整意思；长说明主动加“，”“、”给断点，避免词中断和孤字行。
- 改版式不改正文：不挪位置、不换分隔符、不合并句子（v2 曾因此丢学院全称、专业重复）。要改就写 textFixes 并断言原文。
- 数据：交叉核对源稿；源稿没给的是缺口，写“缺”，不填合理数。
