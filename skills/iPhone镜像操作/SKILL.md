# iPhone 镜像操作

本技能提供操作方法，不包含电脑操控工具、登录状态或权限配置。先确认宿主能列出应用、截图、点击和输入；缺少能力时说明缺口，改为指导用户操作，不调用不存在的旧宿主接口。用户须明确指定手机任务；系统权限由用户决定。

## 从最小可见环节开始

1. 识别当前镜像应用和连接的手机，确保任务对象正确。先截图观察，再点击。
2. 显示“iPhone 使用中，锁定 iPhone 以连接”时，让用户锁屏并放下手机。显示重试时可重试一次；仍失败就让用户检查手机是否在附近及网络状态。
3. 读取画面前将窗口置前。后台窗口可能不完整渲染，低清截图放大不能恢复细节。不要反复猜点。
4. 点操作无效时依次核对：入口、连接状态、窗口焦点、目标对象、输入是否送达，最后再查坐标或工具实现。

## 点击、输入与手势

优先使用当前工具提供的可访问性元素。若只能看图，记录窗口矩形，再将截图坐标换回屏幕坐标；工具如返回逻辑点与物理像素须按当前文档换算，不假设两者相同。

```text
x = 左边界 + 图内x / 截图宽 × 窗口宽
y = 上边界 + 图内y / 截图高 × 窗口高
```

窗口移动或切换桌面后重拍校准。遇到“点击将落到其他应用”时先恢复焦点，不盲改坐标。
中文输入在某些工具/系统组合可能带多余字符。仅在确实要替换整个字段时先全选；输入后截图核对，不因搜索失败就断言功能不存在。
拖拽可能变成长按、主屏幕滚动可能无效。可用搜索找 App 或新图标；常见镜像快捷键为 `cmd+1` 主屏幕、`cmd+2` App 切换、`cmd+3` 搜索，须以当前应用菜单核验。

## 不代劳的授权决定

密码、Face ID、支付、安全或隐私授权开关、描述文件与证书信任由用户操作。不要因为用户授权设置图标就推导出安装配置文件、开启持续权限或对外发送的授权。出现授权决定，说明当前停点与用户需完成的动作。

## 示例：本地 HTML 的主屏幕入口

在用户指定文件和目标名称后，使用快捷指令的文件相关操作与快速查看，再添加主屏幕入口；操作名和路径随系统版本核验。图标素材由用户指定，可用满幅无圆角 PNG，让系统裁切。
本地 HTML 的快速查看行为随系统和版本核验：不要依赖 JavaScript 来首次生成主要内容；优先预渲染静态 HTML，使用 `details/summary`、页内锚点及 `:target`。完整文档包含 doctype/head，UTF-8 声明放在前 1024 字节内。锚点目标提供返回链接。
CSS 横滑、固定顶栏和外链是否可用，应在目标手机实际点开核验；不要把历史经验当作当前系统保证。不能读到目标手机时报告“未真机验证”。

完成后从实际入口打开，确认内容、编码、点击目标与遮挡；“添加成功”提示不足以证明使用成功。不要把本地导出、云盘同步和手机加载混成一个成功状态。
