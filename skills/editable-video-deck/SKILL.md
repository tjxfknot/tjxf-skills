# 可编辑口播课件

把原稿变成能够逐条展示、现场改字并重新导出的背景课件。成品以 1600×1200 画布呈现，右下角保留主播区域。公共版使用系统字体，不附带照片、校徽、录音、项目原稿或第三方字体；不同电脑的换行可能不同，必须重新检查。

## 新建课件

1. 未分页时先用同级 `content-layout-analysis` 做内容规划。保留每段原文的去向，无法核实的数据标 `【待核】`。版式按内容关系选择，字段见 [plan-schema.md](references/plan-schema.md)，14 种版式见 [layouts.md](references/layouts.md)。
2. 先制作代表页，再铺全量。用户已明确授权可直接推进，并记录假设。文字修改必须写入 `textFixes` 并断言原文；不在换版式时悄悄删改内容。
3. 以此 SKILL.md 所在目录为技能根目录，所有命令从该目录执行，输入输出路径由用户项目提供。不要依赖作者电脑上的目录。

```bash
python3 scripts/build_deck.py assets/examples/demo/plan.json assets/examples/demo/content.json assets/examples/demo/demo.html
```

构建需要 Python 3 标准库。本地图片可选用已安装的 `cwebp` 压缩；没有时原样内嵌，过大则拒绝。构建输出 HTML 与同名 `.data.json`。浏览器打开 HTML 后，方向键逐条讲解，工具栏可切编辑、保存、导出、手机预览和语音跟读。

4. 按 [verification.md](references/verification.md) 检查页面载入、逐条展示、编辑保存、导出重开和溢出。项目数据与原稿人工对账；自动检查不能代替内容真实性、电视拍摄和手机压缩后的验收。
5. 给出成品、规划、内容、验证结论与未验项。浏览器本地保存只属于当前浏览器；交付或换电脑前必须导出 HTML。更换 `deck.key` 前先导出现有修改；同一课件修复应保持键稳定。

## 编辑与维护

- 核心编辑台已内联进骨架，自包含，不需要另装 HTML编辑台。支持就地改字、富文本、撤销重做、卡片与页面增删排序、字号间距、拖动吸附、上传底图/配图、批注、JSON 备份和 HTML 导出。契约见 [editor-contract.md](references/editor-contract.md)。
- 主题包与风格选择见 [style-picking.md](references/style-picking.md)。主题包只换颜色和纹理；真正的内容结构由版式决定。
- 不对字号与颜色写 `!important`。影响布局的字段应在生成卡片前应用；新 DATA 字段须纳入 `wbValidate`，否则导入会丢。
- 更新已有本引擎课件的附加模块可用 `python3 scripts/patch_modules.py 原.html 新.html`。只写新文件，先确认输入是本引擎课件。其他历史模板不在本公共版范围内。
- 「录成视频」按钮只导出当前 HTML 并说明需要外部录制工具；本集合不编码 MP4，不包含作者内部工具包。

## 语音跟读与隐私

默认不会收音。用户点击语音跟读后，浏览器会申请麦克风权限。自动模式优先尝试浏览器本机识别，首次准备中文和英文识别包可能触发浏览器下载，需要联网；实际支持取决于浏览器与系统。安装完识别包后，本机识别由浏览器在设备上处理。

本机模式失败时，切换联网识别会先弹确认；直接选择联网模式后启动也会使用浏览器的远程识别服务。在 Chrome 中通常由 Google 提供，音频可能发送给该服务。不要把它描述成所有功能均离线。课件不录制音频，但识别文字和诊断过程暂存在页面内存中；手动导出的跟读记录可能包含识别文字、原稿片段和时间信息，分享前须检查。识别偏好、课件正文与编辑修改可能保存在本浏览器本地存储。

自动跟读可以用不出声预演检查触发点；生产拍摄前仍需真实环境试讲，按键可随时接管。桌面与移动端能力不同，不能保证浏览器支持麦克风识别。

## 来源与分发范围

引擎、骨架和编辑台来自本集合的原有课件技能；内联编辑台核心源于 `HTML编辑台/assets/editdesk.js` 的演进版本，相关编辑交互与 `编辑台配件` 共用设计。公共打包未附加未知来源二进制素材。拼音数据来自 [mozillazg/pinyin-data](https://github.com/mozillazg/pinyin-data)，原数据版本 0.15.0；其原始来源注记与派生 `pinyin.js` 注记必须保留，完整第三方许可随本技能的 `LICENSE.pinyin-data` 分发，并写入成品 HTML 的拼音表注释；不得删除作者、来源和许可。
