# 挑风格：先看三套，再定一套

## 版面方向（先于主题包，2026-10-08 示例）

用户说“不同风格”多半指**版面／排版／展示风格**，不是配色：主题包随时能换，他要挑的是骨架。新题材交付前：

1. 用同一批 3–4 张代表页（开场、一个流程页、一个大类→学院页、一个数字页）出三个方向，**骨架必须不同**（花叔：只换色换字体的会被识破是换皮），配色统一用用户选的那套。
2. 现成可选的三个方向：**A 卡片清单**（11 种卡片版式按内容换）、**C 结构图**（podium／htree／chips，0.4.0 已进引擎）、**B 杂志编排**（大号数字和序号、细线分栏、名单像目录排印——目前只有静态样张 `示例口播课件/版面方向/样张_BC.html`，选它要先做进引擎）。
3. 拼一张对比图（行＝方向，列＝代表页），发给用户挑；用户可能要两套都做好“交替着选”——两套保持页 id、页序一致，按页挑用 `make_mix.py` 那种拼法（示例目录有现成脚本）。

## 主题包（换皮）

2026-10-06 建立（0.3.8）。借鉴 frontend-slides、花叔的“先出几版让人看，别让人凭文字选”。用户审美类指令一律先给看得见的东西。

## 什么时候走

- **要走**：新题材、新主播、新系列第一期；用户说“换个风格”“不够好看”“有没有别的样子”。
- **不走**：同一系列已经定过风格的下一期；只改字、改数据、修故障；用户明说“就按上次那样”。
- 定下来的风格写进该课件的 `说明.md`：给用户看了哪几套、他选了哪套（原话）、是否保留原配色。下次同系列直接沿用。

## 主题包（只换皮，不动骨）

| 主题包 | 气质 | 适合 | 默认配色／底纹 |
|---|---|---|---|
| 经典学院 classic | 稳妥 | 院校盘点、分档讲解，什么题材都压得住 | 课件原来的 |
| 白卡投影 clean | 清爽 | 就业、薪酬、职业这类偏商务的话题 | 学院蓝／纯色 |
| 瑞士网格 swiss | 理性 | 排名、数据、规则和政策讲解 | 浅底钴蓝／细网格 |
| 深色舞台 stage | 醒目 | 开场、结尾、悬念页；暗光拍摄 | 深底青／点阵 |
| 杂志暖纸 editorial | 人文 | 专业介绍、学科故事、人物和城市 | 暖纸赭红／纸纹 |
| 照片衬底 photo | 有现场感 | 有学校实景照片时（先在底图里上传照片） | 课件原来的 |

只改颜色、底纹、卡片底色／圆角／阴影／色条颜色、章节导航、顶部色条；字号、字重、边框宽度、内边距一律不动。`scripts/checks/packs.cjs` 保证每套下卡片位置、尺寸、断行与经典学院逐状态一致（期望 0 差异）。讲到时的高亮底色不覆盖。

“保留课件原配色”：学校有主色（参考绿、演示蓝）时勾上，只换版面风格；深色舞台必须配深色，不受这个开关影响。

## 三套怎么挑（给用户看之前，我来定候选）

按 frontend-slides 的配比：**一套稳妥＋一套鲜明＋一套外卡**。

- 稳妥：经典学院（或该系列已定的风格）。
- 鲜明：按题材选——排名／数据→瑞士网格；开场／悬念→深色舞台；职业／薪酬→白卡投影。
- 外卡：跟题材有关但用户没见过的——有实景照片→照片衬底；人文、学科故事→杂志暖纸。

写进规划：`deck.settings.packPick: ["classic","swiss","editorial"]`（构建后编辑台的“挑风格”默认显示这三套）。不写的话：有上传照片→经典学院／照片衬底／白卡投影，否则→经典学院／瑞士网格／深色舞台。

## 用户怎么挑

1. **在课件里**：编辑模式 → 右侧面板「页面」→ 主题包 →「挑风格：三套并排对比」。同一页、同一讲解状态三套并排，翻页同步；「按手机大小看」切到手机实宽；「换一批」看另外三套；点「用这套」立刻换上，可撤销；满意后导出 HTML。
2. **不打开课件也能看**（发给同事一起挑）：
   ```bash
   node scripts/checks/styles.cjs 成品.html 输出目录 [--packs classic,photo,clean] [--pages 2,4,7] [--keep 1]
   ```
   出 本项目参考文件（行＝主题包，列＝代表页）和 本项目参考文件（每套第一张代表页放进抖音信息流）。默认代表页取第 1 页、卡最多的一页、最后一页。
3. 用户也可以直接在面板里点任一主题包按钮切换。

## 交付时说清

用了哪套、是否保留原配色、`packs.cjs` 结果（0 差异）、手机字号体检结果。
