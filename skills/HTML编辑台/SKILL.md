# HTML 编辑台

给 HTML 装上三件事：**点着改字**、**改完存住**、**导出成新文件**。装完用户自己就能改，不用每次回来找我。

运行时是 `assets/editdesk.js`，342 行，无依赖，直接内联进页面即可。

## 先判断宿主是哪一种

这一步判断错了后面全错。**先看页面里的字是哪来的**：

| | **data 模式** | **dom 模式** |
|---|---|---|
| 页面长什么样 | 有个 `DATA` 对象，DOM 由它渲染出来 | 手写的静态 HTML，字直接写在标签里 |
| 改字怎么走 | 写回 `DATA` 的路径 → 宿主重绘 | 直接改 DOM |
| 存什么 | 整个 DATA 的 JSON | 各字段的 innerHTML |
| 典型 | 分档卡片课件、梯队盘点、数据看板 | 汇报单页、说明页、一次性的展示页 |

拿不准就问自己：**同一份内容改了数据要不要重新排版？** 要 → data；不要 → dom。

## 最小装配

**dom 模式**（新做的静态页，最省事）：

```html
<!-- 想让人改的元素，标上 data-e="随便起个唯一名字" -->
<h1 data-e="title">部门周报</h1>
<p data-e="p1">本周完成三件事。</p>

<script>/* 这里内联 assets/editdesk.js 全文 */</script>
<script>
  EditDesk.init({ mode:'dom', key:'周报', exportName:'周报.html' });
</script>
```

**data 模式**（页面由数据渲染）：

```html
<script>/* 这里内联 assets/editdesk.js 全文 */</script>
<script>
/*DATA_START*/
let DATA = { "ver":1, "title":"…", "items":[ {"name":"…"} ] };
/*DATA_END*/

DATA = EditDesk.boot(DATA, { key:'梯队', ver:DATA.ver });   // 必须在渲染前

function render(){ /* 渲染时给元素标 data-e="items/0/name" 这样的路径 */
  if(EditDesk.isEditing()) EditDesk.setEditing(true);       // 重建后复原可编辑状态
}
render();

EditDesk.init({ mode:'data', data:DATA, key:'梯队',
  exportName:function(){ return DATA.title + '.html'; },
  onChange:render });                                       // 改完怎么重绘，宿主自己说
</script>
```

`data-e` 是**唯一契约**。data 模式下它是数据路径（`tiers/0/items/3/name`，`/` 分层，数字是数组下标）；dom 模式下随便起名，唯一就行。

装进已有 HTML、宿主自带工具条/编辑模式怎么接、导出两种模式怎么选 —— 见 `references/装配指南.md`。

### 缓存认文件

`boot` 会给数据算个指纹存进缓存。**换了一份文件（比如打开历史备份）但版本号没变**，
下次打开也会弹提示条，而不是默默显示缓存那份。提示条上的
「只看一眼文件内容（不动我的稿）」可以临时用文件自带的内容渲染，全程不写缓存，刷新就回来。

## 装完必须验的四件事

不在浏览器里跑一遍就说装好了，基本都会翻车。**逐条验**：

1. **改一个字** → 刷新页面，改动还在（存住了）
2. **点导出** → 把导出的文件**单独打开**，改动在里面（不是只在缓存里）
3. **导出的文件里还有编辑台**（能接着改，不是导出一次就废）
4. **控制台没有报错**

第 2 条最容易漏，也最容易出事——见 `references/踩过的坑.md` 第 1 条。

## 装完告诉用户什么

一句话说清这三点，别让用户以为改完就万事大吉了：

> 点右下角「编辑模式」→ 直接点文字改 → **改完一定要按「导出 HTML」**，
> 下载的那份覆盖原文件才算真的存下来。没导出的话，换台电脑打开就看不到你的修改。

「导出 HTML」按钮上有个 ● 的时候，就是还有没导出的改动。

## 接用户的改动

用户说“我改了”“我放了底图”时，改动多半只在他浏览器里，文件没变：

1. 先 `cmp` 他指的那份文件；没变，就去“下载”文件夹找最新的导出（`…(N).html`），还没有就请他点「导出 HTML」（拍摄模式先按 Esc）。
2. 拿到的导出件原样存一份 `版本备份/uN_用户手改版_改了什么_时间.html`，不动它。
3. 以它为底稿叠我的改动，**不要从我的生成脚本重跑**，那会覆盖他的改字。
4. 清掉编辑残留（回车留下的空 `<br>` 等），逐条告诉他“我动了你哪几处设置”。
5. 要换缓存键或版本号，先确认他手上没有别的没导出的改动。

已知缺口：改动只存在浏览器里是好几次事故的共同根源。候选解法是让编辑台直接写回原文件（Chrome 文件写入接口），本地双击打开的页面能不能用还没验证，验证前不要承诺。
