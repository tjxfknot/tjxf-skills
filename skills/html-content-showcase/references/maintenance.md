# 按需维护与来源登记

仅在用户要求巡检或明确授权周期维护时运行；本包不安装或恢复任何定时器。

每轮范围由任务指定；可先检查已有目录、来源清单与 usage 记录。只访问用户指定或公开来源，不自动登录、发帖或发消息。没有实际采用记录就说明样本不足。

对引入的第三方资源记录：原作者、公开来源 URL、版本/提交、取得时间、文件 SHA256、许可证文件和状态。未核许可标为 reference-only，不复制进交付物。每个新版本分目录保存，不覆盖历史成品。不自动执行下载资源中的脚本或安装钩子。

打包清单示例见 `examples/package.example.json`；示例的 `license_reviewed` 为 false，必须先按真实资源完成许可核验。空目录尚无可浏览试用，需用户自行提供已授权资源并保存验证记录。建议与通知按用户当次授权，不继承原部署的维护频率或历史授权。
